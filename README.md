# BNI The Región · Site completo

Abrir `index.html` o subir toda la carpeta completa a hosting.

Incluye páginas: Home, Originals, Charlas, Podcast, Negocio, Formación, Métricas y Activar comunidad.

No separar carpetas `assets`, `css` y `js`, porque los enlaces internos dependen de esa estructura.
